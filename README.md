# Stay-SMART
This project is used to practice things I have learned in the IT fundamentals bootcamp.

The report page contains a few functionalities to help a user make a report. This includes:

An image of the report form that the user uses to initiate the form.
A step by step bar at the top of each section, so the user knows what step they are in for the report process.
A selection of buttons so the user can select which type of malware they are dealing with.
If none are applicable, then they can type what threat they are dealing with. And it will get added to the list.
A datepicker so they can inform the company when it happened.
And a confirmation section so they can make sure their details are correct.
